# Dark single-card secondary tools carousel

## Goal
Refine the existing secondary tools showcase into a premium dark carousel that emphasizes one tool at a time while revealing part of the next card.

## Changes
- Keep the existing curated non-flagship tool list and links unchanged.
- Resize the carousel so one dominant card fills most of the viewport, with a controlled preview of the following card on desktop and mobile.
- Strengthen the dark card treatment, numbering, category tag, tool name, description, and “Explore tool” link using the existing site tokens.
- Slow the automatic advance while preserving smooth movement, pause-on-interaction, touch scrolling, keyboard access, reduced-motion support, arrows, and slide indicators.
- Make “View All Tools” a stronger high-contrast action without changing its destination.

## Verification
- Check desktop and 411px mobile card proportions, next-card preview, controls, auto-play, touch scrolling, and page overflow.
- Confirm all cards and the all-tools action open the correct pages, with no build, runtime, or console errors.
- Tutorials remain unchanged.
