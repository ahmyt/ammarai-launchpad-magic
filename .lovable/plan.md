# Neo-Swiss Craft Refinement

## Goal
Refine the existing bold AmmarAI homepage without changing its direction, content, structure, or functionality. Preserve the strong Neo-Swiss typography while improving precision, balance, hierarchy, and tactile finish.

## Refinements
- Rebalance the opening composition, headline-to-copy relationship, action spacing, and vertical rhythm across phone and desktop layouts.
- Upgrade the Command Center with more deliberate proportions, cleaner internal alignment, better search and shortcut treatments, and restrained layered depth.
- Refine button sizing, icon alignment, typography contrast, line lengths, and focus/hover behavior while keeping the sharp editorial character.
- Tune section spacing and grid proportions so each section feels composed rather than mechanically repeated.
- Add subtle surface hierarchy, hairlines, shadows, and transitions only where they improve clarity and premium feel.
- Polish cards, comparison, reviews, FAQ, and final action area without changing their content or behavior.

## Technical details
- Keep all changes homepage-scoped and token-based in the existing semantic OKLCH system.
- Preserve the current layout structure, data sources, links, search, videos, review flows, metadata, and accessibility.
- Respect reduced-motion preferences and avoid business-logic changes.

## Verification
- Check 411px mobile, 1280px desktop, and wide desktop for spacing, alignment, clipping, and text fit.
- Verify search, buttons, links, videos, review dialogs, FAQ, keyboard focus, and reduced-motion behavior.
- Confirm no build, runtime, or console errors.
