# AmmarAI Homepage — Major Premium Upgrade

## Goal
Transform the existing light homepage into a materially bolder, more sophisticated product experience while preserving all real content, functionality, links, and the Command Center concept.

## Visual direction
- Keep the selected light neo-glass foundation, but make it architectural rather than decorative.
- Use Bricolage Grotesque with a more confident editorial scale and Inter for supporting copy and controls.
- Create a stronger rhythm of bright editorial space, translucent product surfaces, structured neutral bands, and decisive near-black moments.
- Use one disciplined violet accent, precise hairlines, controlled glow, layered shadows, and subtle dot-grid atmosphere.

## Homepage upgrade
1. Recompose the opening for stronger brand impact, cleaner copy measure, more decisive actions, and a substantially more dimensional Command Center.
2. Turn the Command Center into a polished product console with clearer zones, stronger tool navigation, richer search treatment, and intentional mobile stacking.
3. Give each major section a distinct composition rather than repeating identical headings and card grids.
4. Rebuild flagship tools as a varied editorial showcase with stronger numbering, scale contrast, and featured-tool emphasis.
5. Upgrade video, categories, popular/recent tools, workspace benefits, comparison, reviews, use cases, blog, FAQ, and final conversion areas with section-specific depth and rhythm.
6. Refine the trust strip and transitions between sections so the full page feels continuous and intentionally art-directed.

## Technical details
- Keep semantic OKLCH tokens and homepage-scoped styling in the global stylesheet.
- Add focused homepage classes and minimal presentation wrappers only where needed; preserve data sources and behavior.
- Keep metadata, JSON-LD, CMS-managed comparison content, genuine review flows, media, search behavior, and accessibility intact.
- Respect reduced-motion preferences and avoid hardcoded component colors.

## Verification
- Check phone, desktop, and wide layouts for hierarchy, spacing, clipping, and overlap.
- Verify search, links, videos, review dialogs, FAQ, keyboard focus, and reduced-motion behavior.
- Confirm no console, runtime, or build errors.
