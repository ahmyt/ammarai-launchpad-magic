# Secondary Tools Showcase

## Goal
Add an elegant, continuously moving homepage showcase for useful AmmarAI tools beyond the eight flagship products, inspired by the attached recording but clearer, more polished, and easier to control.

## Implementation
- Place the new section directly after the flagship tools so it reads as the broader AmmarAI catalogue.
- Curate non-flagship tools only, excluding every flagship slug and avoiding duplicate cards.
- Build a wide horizontal carousel with premium editorial cards showing category, tool name, and a concise existing description.
- Auto-advance smoothly, pause while hovered, focused, or being interacted with, and respect reduced-motion preferences.
- Add previous/next arrow controls, clickable position indicators, touch scrolling, keyboard-accessible links, and a clear “View all tools” button.
- Keep links pointed at the existing tool pages and preserve the current Neo-Swiss color, typography, spacing, and card system.

## Verification
- Check desktop and 411px mobile layouts for card fit, smooth motion, controls, touch scrolling, and no page overflow.
- Confirm every showcased card opens the correct tool page, no flagship appears, and the all-tools button opens the catalogue.
- Confirm the page has no build, runtime, or console errors and tutorials remain unchanged.
