# AmmarAI light editorial restyle — first fold

## Goal
Restyle the existing site without changing routes, page count, working features, or lower homepage sections. This pass establishes the light editorial system globally and rebuilds only the homepage header and first fold, then stops for review.

## Changes
1. **Global visual foundation**
   - Make warm paper the default canvas with ink text and one restrained dry ink-blue accent.
   - Use Fraunces for sentence-case editorial headings and Inter for navigation, controls, labels, and body copy.
   - Standardize buttons and cards to rectangular shapes, 1px hairlines, minimal depth, and no glow, glass, grid, or decorative effects.
   - Keep the existing dark-theme control functional, but make the site light-first.

2. **Shared header and footer**
   - Refine the existing sticky header into a thin paper bar while preserving its links, theme control, login, mobile menu, and Start Free action.
   - Bring the existing footer into the same paper-and-ink system without changing its navigation.

3. **Homepage first fold only**
   - Replace the current full-width dark poster treatment with a two-column editorial opening.
   - Use eyebrow “Workspace,” H1 “Work gets finished here.”, concise connected-workspace copy, Start free and Explore AI tools actions, and the free-plan note.
   - Replace the current command-center mockup with a focused Writer frame showing a document, selected paragraph, and rewrite menu.
   - Keep all homepage sections after the first fold unchanged in this pass.

## Guardrails
- No new pages, routes, sections, data, testimonials, logos, pricing changes, or backend work.
- No banned language, purple gradients, black full-bleed hero, model ticker, image wall, mascot, glow, or grid overlay.
- Existing navigation, search, content, URLs, theme switcher, and all lower-page functionality remain intact.

## Validation
- Check the first fold at desktop and mobile widths.
- Confirm the H1 is sentence case, uses no “everything” or “anything,” both actions work, no horizontal overflow appears, and existing routes remain available.
- Confirm preview and build health, then stop for visual approval before changing lower homepage sections.
