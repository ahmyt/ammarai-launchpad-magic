# Compact secondary tools carousel

## Goal
Refine the existing secondary tools showcase so several smaller, readable cards are visible together while preserving its current Neo-Swiss styling and controls.

## Changes
- Show four cards across on wide screens, three on standard desktop, two on tablet, and a readable partial-next-card layout on mobile.
- Reduce card height, spacing, numbering, and type scale while keeping each tool name and short description clear.
- Slow the automatic movement and keep smooth scrolling, pause-on-interaction, swipe support, arrows, and reduced-motion behavior.
- Keep the progress indicator and make the “View all tools” action visually prominent.

## Verification
- Check desktop, tablet, and the current 411px mobile view for visible card count, clipping, readability, and layout stability.
- Test autoplay, arrows, indicators, swipe/scroll, tool links, and “View all tools.”
- Confirm no build, runtime, console, or accessibility errors.
