# Apply the dark enterprise design site-wide

## Goal
Extend the homepage’s restrained dark enterprise visual system across the entire website while keeping every page’s content, links, features, and workflows unchanged.

## Changes
- Correct the shared theme color mapping so dark-mode text, surfaces, borders, forms, tables, buttons, and cards resolve consistently on every page.
- Apply the homepage’s indigo-black palette, fine grid, restrained depth, card radius, typography hierarchy, and section rhythm to public pages, tool pages, blog, resources, legal pages, authentication, and the content studio.
- Preserve the light-theme option in the header and ensure every page switches cleanly between the earlier light design and the dark default.
- Keep tutorial copy, screenshots, metadata, navigation, and tutorial data untouched; only the shared visual theme may affect how tutorials render.

## Validation
- Check representative public, tool, blog, tutorial, legal, authentication, and admin pages on desktop and mobile.
- Verify readable contrast, no horizontal overflow, working theme persistence, one H1 per page, and a clean build.
