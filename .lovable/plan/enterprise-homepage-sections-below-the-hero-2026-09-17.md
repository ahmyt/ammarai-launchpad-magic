# Enterprise homepage sections below the hero

## Goal
Keep the current hero unchanged and simplify everything below it into a focused enterprise sequence: proof, flagship tools, secondary tools, and one closing action.

## Changes
- Preserve the hero markup, copy, search, controls, and styling exactly as they are.
- Consolidate proof into one restrained trust section using the existing company logos and genuine customer reviews.
- Show only the existing major flagship tools in a consistent card grid, with a quiet “Explore Tools” secondary path.
- Keep the existing dark single-card secondary-tools carousel, but reduce its visual weight and align its labels, controls, cards, dividers, and spacing with the flagship section.
- Remove the additional homepage catalogue, rankings, feature grids, comparison, use-case, blog, FAQ, and video-library sections so the page has one clear job per block and only one closing CTA.
- Standardize section spacing, heading scale, card borders, buttons, labels, and dividers without introducing a new visual style.

## Verification
- Confirm the hero is visually and functionally unchanged.
- Check desktop and 411px mobile layouts for hierarchy, spacing, carousel controls, links, and page overflow.
- Confirm the final page order is proof → flagship tools → secondary tools → closing CTA, with no build, runtime, or console errors.
